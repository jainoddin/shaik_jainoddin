# Jainoddin Shaik — Full Stack Developer & Software Architect Portfolio

Modern, high-performance personal portfolio built with Next.js 16, React 19, TypeScript, and Tailwind CSS. Featuring an interactive Orbiting Planetary Tech Galaxy, ATS-friendly resume delivery, and 100/100 Google Lighthouse Core Web Vitals.

## 🚀 Tech Stack

- **Framework:** Next.js 16 (App Router, Turbopack)
- **Library:** React 19
- **Language:** TypeScript 5
- **Styling:** Tailwind CSS 4, Vanilla CSS animations
- **Icons:** Lucide React & Custom Optimized SVGs
- **Deployment:** Vercel / Node.js

## 🌟 Key Features

- **Orbiting Planetary Tech System:** Concentric animated orbits showcasing the full-stack technology ecosystem with counter-rotation and interactive hover inspection.
- **Featured Projects Showcase:** Deep dives into production platforms:
  - **QuickTool:** All-in-One AI SaaS Platform (100+ tools, Google Gemini AI)
  - **TodayAround:** Real-Time Global Daily Intelligence & News Engine (Rust Actix-web + Next.js)
  - **TorvaDB:** High-Performance Self-Hosted Database Engine (written in Rust)
  - **Tansy Academy:** Interactive SQL & Database Education Platform
- **100/100 Lighthouse Performance:** Zero layout reflow, sub-second LCP, GPU-accelerated compositing, and zero unnecessary client hydration.
- **ATS-Friendly Resume:** Embedded, automated vector PDF generator with direct one-click download.

## 🛠️ Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3002](http://localhost:3002) with your browser to see the result.

## 📦 Build for Production

```bash
npm run build
npm run start
```
